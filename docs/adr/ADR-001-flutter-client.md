# ADR-001: Flutter as the mobile client

- Status: Prepared
- Date: 2026-09-19

## Decision

Lumo's Build A client is a Flutter application. This change establishes the application shell, environment configuration, navigation, design-system tokens/base components, API client, and GenerativeUIRenderer.

## Notes

Product screens (catalog, sales, closing) are not implemented here. The four-tab visual identity (Inicio, Hoy, Memoria, Negocio) is preserved.
